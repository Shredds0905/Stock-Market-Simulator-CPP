# 📈 Stock Market Simulator (C++)

A console-based Stock Market Simulator developed in **C++** using **Object-Oriented Programming (OOP)** concepts.

## 🚀 Features
- User Signup & Login (Password masked with `*`)
- Regular & Premium Users
- Buy and Sell Stocks
- Dynamic Stock Price Updates
- Portfolio Management
- Transaction History
- File Handling (Persistent Data)
- Market View (Guest & User)
- CLI Menu System

## 🛠 Technologies Used
- C++ (OOP)
- File Handling
- Dynamic Memory Allocation
- Console Programming

## 🧠 OOP Concepts Implemented
- Classes & Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Constructors & Destructors
- Static Members
- Friend Class
- Dynamic Memory Allocation
